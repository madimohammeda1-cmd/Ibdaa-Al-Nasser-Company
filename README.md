## 🛠️ التطوير

### إضافة ميزة جديدة:

1. أضف API في `api/`
2. أنشئ صفحة HTML
3. أضف CSS في `assets/css/style.css`
4. استدعِ الـ API من JavaScript

### تعديل التصميم:

1. عدّل `assets/css/style.css`
2. استخدم متغيرات CSS المعرّفة
3. تأكد من التوافق مع الأجهزة

### إضافة JavaScript:

1. استخدم الدوال الموجودة في `assets/js/main.js`
2. أضف دوال جديدة حسب الحاجة
3. استخدم Async/Await للطلبات
